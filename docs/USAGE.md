# chatbook の使い方

- 種別: 利用ガイド
- 対象: 本棚・選択して質問・ハイライト・読書位置・キーボード操作など、画面から触れる機能すべて
- 想定読者: chatbook を自分のインスタンスで読書に使う人
- 最終更新: 2026-08-21

セットアップは [README](../README.md) にある。ここは画面の操作だけを扱う。

## 本棚に技術書を並べる

本棚に並ぶ本の最後にある「PDFを追加」を押して PDF を選ぶか、PC なら PDF ファイルを本棚に
ドラッグして落とすと、1 ページ目から表紙が作られて本棚に並ぶ。終わるとそのままリーダーが
開く。カードには表紙とページ数が出て、押すとリーダーが開く。

処理中は画面いっぱいに進み具合が出る。「PDFを読み取り中...」→「アップロード中 45%」→
「保存中...」の順。読み取りはページ数で伸びるが 449 ページでも 1 秒ほどで終わり、
**待ち時間のほとんどはアップロード**——つまりファイルの大きさと、手元の回線の上り速度で
決まる（22MB の本をスマホから足すと、送信だけで 1 分以上かかる）。

PDF でないファイルや 2 つ以上のファイルを落としたときは、どちらも追加されず本棚の上に
理由が出る。

同じ本をもう一度追加しても本棚には増えない。**中身が同じなら同じ本として扱われる**ので、
読んでいた場所やハイライトもそのまま残る。ファイル名を変えて追加し直せば、
本棚の表示名だけが新しくなる。

本を消すときはカードの削除ボタン。「ハイライトとチャット履歴も削除されます」と確認が
出るとおり、その本に紐づくものは一緒に消える。

## 気になった箇所を選んで AI に聞く

本文をドラッグで選ぶと、そのまま質問できる。何で触ったかで出るものが変わる。

- **マウス** — 選び終わった位置に入力欄が出る。「選択した文章について質問する...」に
  書いて「質問する」
- **指** — 画面の下端にバーが出るので「AIに質問」を押す（入力欄を先に出すと、
  フォーカスを取った瞬間に選択が畳まれてしまうため）

選んだ一節は質問に付いて送られるので、「これはどういう意味?」だけで通じる。回答は
ストリーミングで流れてくる。出る場所は画面の広さで変わり、広い画面では右のチャットパネル
（ヘッダの「チャットを表示」/「チャットを隠す」で開閉する）、狭い画面では下から出るシート
（→「スマホ・タブレットでも読める」）に出る。

回答は新しい行が出るたびに一番下へ送られていく。**最初から読みたくて上へスクロールすると、
その回答の間は送られなくなる**。末尾まで戻せばまた送られ、次の質問の回答も送られながら出る。

回答が長いときは、広い画面ならヘッダの「チャットを最大化」でページを隠し、チャットだけに
できる。ページは隠れるだけなので、「最大化を解除」で読んでいた場所にそのまま戻る（最大化は
覚えていないので、本を開き直せば元どおり並ぶ）。狭い画面ではシートを広げる（→「スマホ・
タブレットでも読める」）。

質問と一緒に渡るのは、選んだ箇所が属する**章の本文**（目次の無い PDF では選んだページの
前後 10 ページ）。同じ章の中のことは踏まえて答えるが、章の外のことを聞くと「表示中の
ページには無い」と答えることがある——そのときは該当の章を開いて選び直すか、Web 検索に
補わせる。最初の一文字が出るまで数秒かかることはある（止まっているわけではない）。
この機能より前に追加した本も、一度開けば目次が保存され、それからのチャットは章単位に
なる（何もしなくてよい。目次を持たない PDF だけは前後 10 ページのまま）。

本文だけでは足りない質問のために **Web 検索が既定で ON**。設定メニュー（ヘッダの
歯車）の「チャット > Web検索」で切り替えられる（Web 検索を持たないプロバイダに向けて
いるときは、このトグルごと出ない。→ [接続先とモデルを差し替える](LLM_PROVIDERS.md)）。

## 本そのものに聞く（要約・章ごとの質問）

本文を選ばなくても、本について聞ける。チャットパネルのハイライト一覧の上にある
**「本について質問する」**（ハイライトが 1 つも無い本では、案内文の下に出る）を押すと、
その本の会話が開く。**本ごとに 1 本**で、ハイライトの会話とは別物。

質問ごとに、根拠にする本文の範囲を選べる。会話の右上の「範囲: 本全体」を押すと章の
チェックボックスが出る。

- **本全体** — 最初から最後まで。要約を頼むときはこれを選ぶ
- **章を選ぶ（複数可）** — 目次にあるトップレベル章。選んだ章のページだけが渡る。
  隣り合う章を選ぶと 1 つの範囲にまとまる
- 選んだものが無い状態に戻すと本全体。目次の無い PDF は「本全体」だけ

同じ会話の中で範囲を変えてもよく、前の質問と答えはそのまま残る（「全体を要約して」の
あとに「3章をもう少し詳しく」と聞ける）。

**大きい本の「本全体」は、モデルが一度に読める量を超えることがある。** そのときは
エラーが出るので、章を選んで聞き直す。範囲のメニューには各章のページ数が出ているので、
目安にできる。

## 回答の出典から本文へ戻る

回答の下に出典が並ぶ。本からの引用にはページ番号が付いていて、押すとそのページへ飛ぶ。

引用文が本文に見つからなかったときは、そのことが出典に表示される。**AI が本文どおりに
引用しなかった可能性**に気付ける唯一の手がかりなので、理由（引用文が空 / 本文に無い /
1 ページの本）を潰さずに出している。

## ハイライトと会話は残る

質問した箇所はハイライトとしてページに残る。チャットパネルの「ハイライト N件」の
一覧から選べば、そのときの会話を開き直せる。ページ上のハイライトを直接押しても同じ。

## 続きから読む

ページと開いていた会話が自動で保存される。本棚から開き直せば続きから始まるので、
**PC で読んでいた本の続きをスマホで開ける**。開いていた会話は、ハイライトの会話でも
「本について質問する」の会話でも同じように戻る。広い画面では目次とチャットパネルを畳んだ
状態も本ごとに残る（狭い画面のシートは毎回閉じた状態から始まる）。

リロードや共有リンクで開いたときは、URL が指す場所（`?page=` / `?selection=`）が優先される。
古いリンクを開いて何もせずに閉じても、別の端末の読書位置は動かない。

## 読み方を調整する

- **目次** — ヘッダの「目次を表示」から。今読んでいるページを含む項目が強調される。
  目次を持たない本では「この本には目次がありません」と出る
- **見開き** — PDF を表示する領域に 2 ページ分の幅があれば、自動で 2 ページ並べる。
  チャットパネルを畳んだり、ページを縮めたりすると 2 ページになる
- **拡大・縮小** — Ctrl + ホイール（トラックパッドならピンチ）、指ならピンチ。
  倍率は**本ごとに覚える**
- **ページ送り** — ページの左右をクリック / タップ、指なら左右スワイプ、キーボードでも。
  拡大しているときは端を触ってもページは送らず、ページの中を動く

**方向キーはどの設定でも効く**（「なし」を選んでいても）。Shift を押しながらの方向キーは
文字の選択に使うので、そちらは奪わない。

| 操作           | 方向キー |
| -------------- | -------- |
| 次のページ     | `→`      |
| 前のページ     | `←`      |
| 下にスクロール | `↓`      |
| 上にスクロール | `↑`      |

それに加えて、設定メニューから Vim / Emacs / なし を選べる（既定は Vim）。

| 操作           | Vim  | Emacs   |
| -------------- | ---- | ------- |
| 次のページ     | `l`  | `C-f`   |
| 前のページ     | `h`  | `C-b`   |
| 下にスクロール | `j`  | `C-n`   |
| 上にスクロール | `k`  | `C-p`   |
| 目次の開閉     | `t`  | `C-c t` |
| 最初のページ   | `gg` | `M-<`   |
| 最後のページ   | `G`  | `M->`   |

## スマホ・タブレットでも読める

狭い画面では 1 カラムになり、下端のツールバーの両端が目次とチャットになる。チャットは
下から出るシートで、上端をタップすると半分の高さとページの領域いっぱいを切り替えられる。
ページを読み進めながら回答を読めるよう、全部まで広げてもツールバーは残り、ページ送りはできる。

本を足すのは「PDFを追加」のタイルから。指で触る端末にファイルのドラッグ&ドロップは
無いので、そこではタイルが唯一の口になる。

タブレットのように「画面は広いが指で触る」端末でも、選択したときは指向けのバーが出る。
